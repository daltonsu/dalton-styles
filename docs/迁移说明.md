# Dalton Styles 迁移说明

## 内容来源

设计与示例目录参考本地 `standard-platform-ui-kit`，Tunpla UI 3.7.0，源提交 `7f2148d874eb4c2c6b24c78ae7a73ca7658a76a6`。

迁移了 87 个栏目、208 个示例的分类与标题，以及 32 位客户、8 个商机的模拟数据。演示界面和交互改为 React、Ant Design 与 Recharts；不加载旧项目的 DOM 脚本或全局样式。

本项目为个人使用的私有项目。参考项目的授权边界没有因技术迁移发生变化；未增加对外再分发许可。

## 信息结构

- `/`：留白首页，组件库与页面样例两张缩略图。
- `/#/components/:id`：组件分类、搜索、独立组件地址、交互示例和 React 实现。
- `/#/components/standards`：共用色彩、排版、尺寸与交互约定。
- `/#/examples/overview`：经营概览。
- `/#/examples/customers`：客户管理、编辑、详情、筛选与导出。
- `/#/examples/pipeline`：商机看板。
- `/#/examples/settings`：显示偏好与演示数据管理。

使用 HashRouter，以便静态托管与刷新直达，无需服务器配置路径回退。

## 实现与复用

`src/app/theme.ts` 统一配置 Ant Design 主题，`src/styles.css` 负责页面组合和响应式布局。组件示例位于 `src/catalog/demos/`，`manifest.json` 记录栏目与示例。页面和组件演示使用同一个 ConfigProvider；业务数据模型独立在 `src/domain/`。

展示的示例调用引用本项目的 `ComponentDemo`。每页可以打开真实 React 源码；复制到其他项目需要同时迁移对应示例文件、`shared.tsx`、相关依赖及主题。当前交付是应用源码和展示站，没有发布可安装的 npm 组件包。

## 业务演示边界

- 使用固定演示基准日 2026-11-16，与系统时钟无关；示例币种沿用 IDR，界面为简体中文。
- 客户和商机保存在 `dalton-styles:workspace:v1` 本地存储中。损坏数据回退为初始样例；存储写入失败时显示提示。
- 客户支持组合搜索筛选、排序分页、跨页勾选、批量分配、列设置、新建编辑、详情跟进、删除与 CSV 导出。
- 商机支持拖拽和选择器两种阶段切换方式。
- 组件示例的上传仅用于本地文件选择，验证码不进行真实身份验证；异步保存为明示的模拟交互。
- 没有真实账号、权限或后端服务，也未配置部署和 CI。
